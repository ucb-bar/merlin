# src/merlin/analysis/dse

This owner groups hardware/interface search, design-pressure reports and
workload-based guidance. Search explores declared spaces; pressure derives
interface requirements; guidance distinguishes measured evidence from analytical
estimates. Keep those responsibilities and their CLI entrypoints together here.

Preserve evidence tags, explicit target/workload inputs and unknowns. A predicted
cost or ranked candidate is not measured performance, numerical acceptance or a
qualified backend. Generated reports belong under the selected `out/` root.
Moving code into this namespace does not enlarge a compiler SDK or candidate's
source grant; research controllers and independent evaluation retain their roles.
