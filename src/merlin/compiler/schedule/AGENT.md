# src/merlin/compiler/schedule

This is the canonical library for target-neutral scheduling algorithms. Backends
supply derived resource geometry, instruction effects and physical encoders.
Schedules never establish target arithmetic, completion or execution qualification
merely by being constructed or passing their conditional checks.

## Block scheduling owners

- `model.py`: command, contraction, geometry and knob declarations.
- `block.py`: storage placement, contraction nests, load grouping and command order.
- `residency.py`: complete synchronous operand and accumulator lifetime checks.
- `convolution.py`: bounded gathered convolution panels and resource enumeration.
- `readout.py`: retained accumulators and explicitly typed spatial drains.
- `execute.py`: neutral execution at the actual scheduled addresses.
- `interface.py`: interface-command adaptation without silently dropping work.
- `blocks.py`: the explicit public block API; implementations stay with their owners.
- `standalone.py`: derive one vendorable module from those actual source owners.
- `derive.py`: project selected facts into geometry; no literal target defaults.

## Invariants

Review `src/merlin/AGENT.md`, `CLAUDE.md` and the architecture reference. Preserve
the loop, reduction, tail, effect, alias and numerical obligations of each family.
No target name, benchmark result or source provenance may choose an optimization.

The same contraction nest serves matmul and gathered convolution. A block's
identity includes its gather; equal positions can carry different bytes. Every
constructed block schedule passes residency and reduction-lifetime checks before
returning. The neutral executor follows the named addresses rather than rebuilding
the mathematical expression from the contraction.

Target-specific legality and profitability remain separate. Knob defaults are
starting points for measurement; no loop order, lookahead, retention or placement
policy is universally profitable. Geometry comes from selected facts. Unknown
capacity, completion or shared backing without an alias model must refuse.

The vendorable artifact is generated by `standalone.block_schedule_source()`.
It contains the actual owner definitions and their source hashes, with internal
imports removed. It must execute without importing Merlin. Never maintain another
editable copy of the scheduling algorithm or copy the public aggregation module
as if it were a closed implementation.

SDK26 names canonical owners. Frozen V6–V25 rosters and releases stay unchanged;
older exports require an explicitly selected reviewed frozen release. Never stage
current code under an older SDK identity or widen candidate grants to repair an
unclosed source selection. `library_sources` is the explicit shared owner roster;
source identities do not grant access or establish transitive closure themselves.

Admission recording in `library_sources` passes through the original result or
exception. A recording failure never changes a compilation result. Reports are
author feedback, not grants, independent proofs or hardware qualification.

Keep the existing high-value suites: block numerical execution and mutation
controls, emitted-stream comparisons, independent schedule/source checks, closed
SDK import plus actual edited-pass execution, and actual standalone vendoring.
Extend an existing obligation rather than creating a test per helper.
