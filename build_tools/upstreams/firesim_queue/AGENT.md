# FireSim queue input handoff

Keep thin opt-in patches and exact source pins for the external queue here.
External source copies, fake queue state and native receipts belong under out/.
Never install or restart the shared daemon as part of these tests.

The selected file and slot lists are byte-check scopes, not hardware or complete
consumer authority. The physical owner must join them to the actual generated
manager/slot roster. Preserve legacy dispatch when the option is absent,
mandatory teardown after any FireSim launch, and the lifecycle resource lock.
No target interface, ISA, boot/loading, compiler seed or timing model belongs here.
