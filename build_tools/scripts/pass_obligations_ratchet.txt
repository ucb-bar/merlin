# Pass-obligation debt that MAY ONLY SHRINK.
#
# Each line is `<pass name> <axis>:<item>` — scoped to BOTH the pass and the axis on purpose. A bare
# pass name would let an accepted missing obligation silently excuse that same pass later going dead;
# a bare axis would let one pass's debt forgive every other pass's.
#
# Axes:
#   obligation:undeclared        the pass discharges none of the four production obligations
#   requirement:no-capsule-declares-it
#                                no concrete capsule declares the pass's requirement class
#   dialect:<fields>             input_dialect / output_dialect could not be determined
#   exercise:no-capsule-runs-it  MEASURED dead: instrumented, and no recorded capsule run invoked it
#
# NEVER ADD A LINE. A new entry means a pass whose reason to exist nobody can state, or one nothing
# runs — delete the pass, or state the obligation, instead.
#
# Regenerate the audit with:
#   build_tools/scripts/check_pass_obligations.py --ratchet build_tools/scripts/pass_obligations_ratchet.txt
#
# No accepted debt. Frontend numeric normalizations and synthetic research passes live in separate
# registries, so the production gate neither launders them into target obligations nor claims a real
# capsule exercised code it did not call.
