# Native memory-reference tooling

Source-only FASED wrapper, explicit native-build orchestration and bounded
memory-boundary probes. Generated artifacts belong under task output, never
here. Do not change FireSim timing expressions or parameters to obtain trace
agreement. Preserve assertions, source/tool hashes, target-cycle phase, reset
identity and runtime overrides. Native boundary equality does not establish
whole-SoC or deployed-FireSim equivalence. Keep the production replacement gate
closed until those independent conditions are demonstrated.
