# Compiler source provenance

[provenance.json](provenance.json) maps the imported compiler infrastructure to
its development and companion repository revisions. Preserve these identities
and the repository's LICENSE and NOTICE when preparing a source distribution.
The listed commits identify source ancestry; they do not supply companion
repositories, native binaries, model data or independently executable results.

For contributor entry points, use [the compiler guide](../../../docs/guides/compiler_contributions.md).
For installation, selected input requirements and reproduction limitations, use
[artifact evaluation](../../../docs/guides/artifact_evaluation.md).

Runtime evidence, private comparisons and operator journals are not source
release inputs. No completed-campaign, model-accuracy or performance claim is
made by this provenance record. Independent numerical and physical validation
remain necessary for any compiler produced using these sources.
