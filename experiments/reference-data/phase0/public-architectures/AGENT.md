# Public development architecture inputs

These byte-preserved public configuration files contain no weights, captured
validation graphs, inputs or answers. `provenance.json` binds upstream URLs,
resolved revisions and exact SHA-256 values. Use architecture-informed shapes
only as disclosed development data; do not label them unseen transfer tests.
New captures and generated corpora belong under the configured artifact root.

`defaults-provenance.json` separately pins public source snapshots from the
selected local Transformers package. Resolve omitted configuration defaults and
connector geometry only under that exact source/version; this is not authority
for every historical library version or for private validation models.
