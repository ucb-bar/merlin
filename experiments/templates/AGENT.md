# Shared experiment inputs

Target-independent authored templates shared by catalog definitions. These are
workflow inputs, not generated output or a second implementation of phase engines.
Definitions select them explicitly; do not add implicit checkout defaults.

`phase0/performance.yaml` owns the shared performance-family declarations. Target
recipes supply target facts without copying or redefining these comparison policies.
Preserve family identities, claims, grading semantics and frozen-run provenance.
