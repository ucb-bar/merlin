## Supported submode, deliberately narrow

A changed function has exactly two inputs and one top-level changed static loop;
source loop bodies are region-free. Controls are static nonnegative ordered
bounds, positive constant stride, count greater than factor, count divisible by
factor (no unroll tail), factor2..4, tile2..16, one..four ordered word carries,
index32 or index64. Nonaligned original upper bounds are possible when the derived
trip count satisfies these conditions; bulk and segmented bounds are reconstructed
from actual operations and checked against the emitter's equations. Generated
nested segmentation regions are represented completely.

Host guards also check signed bounds for generated lane/stride/add/min values;
Lean W-bound/literal/control obligations are still emitted and must be checked.
Syntax is bounded at2048 operations per module and4MiB per input/query. The frozen
emitter bounds retained lane calls at16 and symbolic expression work independently
of trip count. Only signless scalar word values of width1..256 and index values are
admitted. Overflow flags, tensors/memrefs/floats in value slots, internal/nested
symbol calls, unknown CFG/region semantics, dynamic/empty/inline/tail modes,
unsupported widths, and unchanged SCF entries lacking the selected bridge refuse.
Pre-loop prefixes must contain only selected pure word primitives and concrete
control literals; original index arithmetic outside the generated bridges refuses.
Retained partial region-free operations remain arbitrary stateful external steps;
empty get_effects is not used to prove their success.

For scalar/SCF, the primitive interpretation is explicitly total, deterministic
and state-free. External steps may fail and need only the local successful-result
arity contract. For integer prefix, use the existing exact wrapping BitVec primitive
and canonical signless word inputs. External successes on canonical operands must
produce canonical declared results. This LOCAL law permits deriving reached
intermediate typing; it is not assumed globally. Neither profile assumes source
success. Static typing/initialized reads, successful execution, absence of poison,
physical runtime binding and native numerical fidelity remain separate obligations.
