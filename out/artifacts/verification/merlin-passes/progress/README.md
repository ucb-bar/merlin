### 3. Qinner details

The concrete decoder supports static unencoded i1/i8/i16/i32/i64 and f16/f32/f64 tensors.
It checks exact length, little-endian row-major interpretation and canonical byte-per-bool
storage (00/01); it preserves exact scalar bits without evaluating or normalizing floats.
Unsupported types/layouts and noncanonical bool storage refuse.

`QinnerDecoded.program_equal` uses an explicit source interpretation: tagged empties denote
named archive tensors, and the target receives the same decoded tensors as ordered arguments.
It is not literal equivalence to ordinary `tensor.empty`, which denotes poison in the frozen
semantics. Typing and initialization of added tensors do not prove whole-model successful or
poison-free execution. Common external-call behavior remains a premise.

Eleven program and sixteen decoder receipts replay. Nine positive synthetic program boundaries
perform 18 lifts; retained SmolVLA and TinyLlama boundaries have zero lifts. Do not infer positive
model transformation coverage from those unchanged boundaries. Archive authenticity and the
host loader/C/compiler/runtime implementation of delivery remain outside the decoder proof.
