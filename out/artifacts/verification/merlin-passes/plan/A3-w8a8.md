## D1–D5: before the spec is frozen

1. **Side theorems** (independent of the spec's details):
   - **Exact `i32` accumulation.** With both operands in [-127, 127], an accumulation of length `K`
     is exact over ℤ when `K · 127² < 2³¹`. The checker computes `K` from the actual operand types.
   - **Clamp before convert.** `fptosi` after a clamp to [-127, 127] is defined for every non-NaN
     input. The NaN case follows whatever A2's spec declares.
2. **Scalar quantize-body proof skeleton.** Prove it against a placeholder shaped like design §5.5,
   with the multiply-by-reciprocal order the pass emits. Switch to A2's statement when it's pinned.
   Expect to adjust; don't build the tensor layer on the placeholder.
3. **Hints.** The pass tags each emitted op with `prov.*` roles (`_carry_prov`). Read them as
   untrusted site hints for matching. The checker must recompute structure, maps, shapes and bodies.
4. **Study the actual output.** Use A1's recorded boundary, or until A6 lands the
   `prepare-quantize-int8` stage, the diff between `prepare-qinner-lift/after.mlir` and
   `prepare-lower-quant-ext/before.mlir`. Catalogue the exact op structure per contraction: abs-max
   reduction, scale with floor, reciprocal, quantize generic, `i8` weight reuse (including the
   transpose of captured `i8` weights), `i8 × i8 → i32` contraction, requant generic.

## D5–D9: the proof

1. **Tensor layer.** Prove the abs-max reduction and the per-row scale, the quantize generic, the
   integer contraction, and the requantization against `P`. Reductions keep lexicographic order
   (ledger A5). Floats stay parametric: the operation order must match the spec exactly.
2. **Site rule.** Match one source contraction to the pass's emitted group. Check every operand
   mapping, every shape, the maps and iterators, and fresh names. Compose it through the existing
   rule checker.
3. **Source definedness** for the boundary's input on initialized inputs. Reuse the existing
   definedness books and add only what's missing.
4. **Accept the actual boundary** from the chosen model. All contractions must be verified or
   individually abstained, with a reason.
5. **Mutation matrix.** Each mutated output must pass MLIR verification and be refused by the
   checker. Include at least:
   - the scale floor removed or changed;
   - `roundeven` replaced by `round`;
   - clamp bounds at ±128, or the clamp missing;
   - the requant multiply order swapped;
   - accumulation in `i16`;
   - the scale computed over the wrong axis;
   - a weight scale taken from the wrong channel;
   - a swapped contraction operand.
6. **Native companion test.** Compare before and after the pass against an independent reference
   computed from the spec, on finite samples. Use the pinned PyTorch oracle where TorchAO is
   available.
