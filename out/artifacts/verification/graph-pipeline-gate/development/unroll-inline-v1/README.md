## Actual producer and proof connection

Pinned `unrolling.py:_unroll_one` selects the inline path when
`witness.iterations <= witness.factor`. It begins with the original `iter_args`.
For each lane it emits `lower+lane*step` as an index constant, clones the body via
`_repeat_body` with the current IV/carries, and uses that clone's yield as the next
state. It replaces the original loop's results with the final state. At count0,
no replacement operations are emitted and the original initial carries replace
the results directly. Production replay associates the complete actual target
with this implementation; its witness is a diagnostic, never semantic proof.

`GraphStatePipelineInline.lean` connects the unchanged Scalar loop evaluator to
W's `CountCorrect`/Pipeline `indexIterations_count` progression. `empty_no_body`
returns the initial carries/world for arbitrary partial bodies. The counted
continuation root retains both success and failure; `failed_continuation` retains
the terminal fault/world and suppresses further calls. No evaluator is replaced.

The emitter decodes complete source and target Programs independently. It derives
the original prefix frame, initial carries, original body and continuation from
actual SSA indices. The target is the complete actual inline Program, not a
fabricated reference body. The closed `actual_inputs` proof reduces those actual
terms and splits each remaining partial call using only its local successful
arity. It includes every lane AND final observer. This expansion is bounded by
factor<=4 and sixteen call occurrences; no unbounded trip-sized execution is
used. `all_goals` case splits apply only where simplification leaves obligations;
no goal is admitted or replaced by an assumption.

All defined entries are then lifted by the unchanged Pipeline `entries_cons`
root to `PreservesEntries`. Names/declarations/module metadata remain in the
complete host association and projection. The pure-declaration Query has24 roots
for nonempty cases and25 for empty (the extra skipped-body root); each request
binds21 project Lean source modules. There is no runtime provider selection.
