# First-round design plan

- **Corpus:** Cover the admitted integer cohort: movement; resident/reused int8 matmul across M/K/N tails and deep-K capacity regimes; i32/i8, `acc_scale`, ReLU, and maxpool commits; NHWC conv2d/im2col; attention-QK; and mixed model/host-lane capstones. The public workspace also contains bf16 comparison capsules outside the generated 34-capsule scope.
- **Input ingestion:** Register a self-contained typed `merlin_iface` xDSL dialect and use xDSL's parser, SSA/type checking, operation walk, and `verify()`; register upstream xDSL dialects for linalg model modules. No lexer, regex, or line-oriented MLIR parser is used.
- **Dialect + lowering:** Define verified `gemmini` xDSL operations for configuration, DMA, preload, compute, store, and termination. Rewrite interface operations to a target program, with generic im2col and 16x16 M/N/K tiling passes under `targetgen/synthesize/`, `targetgen/generate/`, and `lowering/`.
- **Encoding:** Derive DIM=16, i8/i32 datapaths, capacities, custom-3 opcode 0x7b/funct3=3, and legal functs from the granted RTL/header facts. Pack command fields exactly as `gemmini.h`; use `isa_tools.py asm`, then disassemble/lint every emitted artifact.
- **Addressing + termination:** Kernel arguments follow interface tensor order; every off-chip DMA address is `llvm.ptrtoint` of the corresponding pointer plus a compiler-derived byte offset. Scratchpad/accumulator addresses are bounded constants. End with FLUSH/fence/return as required by the decoded trace and harness.
- **Lever routing:** Implement the enumerated spatial dataflow, accumulator residency, capacity-fit, descriptor reuse, DMA overlap, loop-offload, and operand-major layout axes in the tile-program emitter; there are no CCA orphan fields or routes.
- **Verification loop:** Establish a valid manifest and all four CLI paths first; test one single-tile capsule, then tails/deep-K/conv/epilogues, running ISA lint/disasm before each narrow self-check. Run the mandated all-capsule Spike check after every package build, shape coverage frequently, and finish with one full check.
