# Reports: Gemmini

This directory contains aggregated evaluation reports for all Gemmini method runs.

Files generated by `python -m harness.cli compare --target gemmini`:
- `metrics.csv` — one row per run, full column set, NA for unmeasured metrics
- `ablation_table.md` — one row per method, mean ± std across seeds (smoke runs excluded)
- `summary.md` — high-level summary of runs and methods

## Interpreting the ablation table

Smoke-test runs (`is_smoke_test: true`) are excluded from the ablation table.
They appear in `metrics.csv` with `is_smoke_test=True` for audit purposes.

The real v0 baseline run should be the first non-smoke row in the ablation table.
