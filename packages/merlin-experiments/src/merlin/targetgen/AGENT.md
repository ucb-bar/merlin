# Trusted experiment evaluation

Checked-source selector v2 explicitly selects the original direct-pointer
execution protocol through the same sealed child. Only an issued live selector
chooses this route; emitted ABI metadata or a copied verdict cannot. Retain the
original whole-program executor and V1 defaults, complete-output comparison and
independent source/packet owner. No global plan is fabricated and no numerical,
timing or scheduling qualification follows from ABI transport alone.

`checked_source_model_diagnostic` explicitly selects complete sealed public
integer source diagnostics through a live reviewed effect issuer. The original
sealed model child v4 restores the same registry/factory and exact selected
context before reusing ordinary package emission and native L2 execution.
The finish consumer independently recomputes original L0/L1/L2 and invokes the
actual source/packet/all-output owner. Missing/failed roles and changed products
refuse. Original required tiers remain intact; L3 stays pending and the result
is diagnostic/incomplete, with no public-program basis, placement, certification,
timing or promotion authority. Defaults and old child schemas are unchanged.
The issuer owns its leaf trace lease; never hold a parent CPU lease across it.
The checked selector groups only adjacent pass/role metadata getters in its
original opted-in registry transaction. Original owner checks run at both
boundaries; selector source/callback checks remain fresh before and after those
getters. Return metadata only after the final check. Never extend this scope
across compilation, native execution, tracing or current source qualification.

Owned-host model preparation, frozen placement and linked-device audit use the
core capture-bound exact grouping helper. They must inspect the same selected
output-fusion cuts as ordinary emission, with unchanged source, complete-output,
host-compute and mandatory-tier obligations.

Explicit ordinary public-program execution retains the source-owned runtime
bundle and binds the actual complete-call caller, same ELF and raw outputs.
Public sources with no accelerator obligations may have empty required device
classes only under their original public basis and explicit false acceleration
demand. Independent source eligibility, source/task CFG, object/ELF/ISA and full
numeric/mandatory-tier checks still run. Optional legal accelerator lowering is
allowed; no placement strategy follows from zero mandatory device obligations.
Existing declared acceleration demand always retains its nonempty mandatory
family-matched device dispatch proof. No strict component role is added.

Contains evaluation implementations, not generic compiler package invocation.
Package/runtime primitives and stable error identities live in core package_runtime.
The common.access registry must name every withheld implementation before moving
it. Preserve grading, failure-plane, AET record, and monkeypatch behavior.
No competing targetgen/__init__.py: core extends that package path.
`group_capsules` owns corpus writing/promotion and grading; it reexports the exact
deterministic entry builder from core `group_capsule_entries`. `store_probe` owns
measured backend capacity sweeps. Neither operation is compiler-core metadata.
Golden evaluation keeps local compatibility adapters for provenance queries:
`capsule_golden._load_golden_yaml` and `capsule_golden.golden_source` overrides
must still affect subsequent queries. Shared metadata policy lives in core
`golden_provenance`; direct reexports would change the legacy globals lookup.
Production codegen smoke kernels and prerequisites belong to selected OOT support
backends. `capsule_runner.codegen_smoke` only dispatches and validates tri-state
evidence: broken providers refuse admission; missing coverage is never a pass.
Simulator identity and ISA class must not select a target-specific compiler.
Prompt queries select an already-loaded evaluator's callbacks without importing
the optional evaluator; its adapters must delegate to pure queries, not selectors.
`numeric_falsifiability.audit_outputs` checks the existing constant candidates
against already selected outputs. Strict callers must report unavailable,
non-finite or unsizeable oracle outputs as unmeasured, never as an assessed pass.
The public CI gate may explicitly allow a partial audit; it never changes a
numeric policy, writes an answer key or grants full corpus numerical coverage.
The integer capsule golden must refuse noninteger operand formats when no
matching independent golden was selected. Integer surrogate stimuli cannot
establish fidelity or falsifiability for a declared floating program.
Only typed `UnavailableGolden` refusals may pass an explicitly partial audit.
Malformed stored outputs or archives and evaluator failures stay hard failures.
Candidate mandatory-tier re-audits inherit the trusted invocation's explicit
ReadbackPolicy from the model context and selected oracle adapters. Default and
B64 reopen text; selected binary readback reopens raw bytes and checks the
complete declared value roster before ordinary numerical comparison. A result
record, console filename or apparent byte format cannot select the transport.
Decoding full values grants no build, source, dispatch or hardware authority.
`native_model_output_binding` may join differing compiled/source output names
only through the original ordered capsule/golden provenance, identical source
bytes and the checked typed mixed-program return/ABI plan. Keep actual packet
and output hashes under compiled names; compare complete values under unchanged
source names/policies. Saved tier/timing consumers reconstruct this join from
original pins, never trust a copied alias list. The helper remains grader-only.

`capsule_scheduling.run_pipelined` copies the selected caller context into each
original calibration and grade worker. Keep original dependency order, full
roster and worker joins; copied contexts carry existing package/resource owners,
never new numerical or timing authority. Explicit operator-small-first feedback
ordering selects only ready/admitted operators before models and preserves immediate
completion callbacks; absent selection keeps legacy ordering. Explicit
`measured-longest-first` starts ready/admitted members by this run's newest measured
per-tier cost (selected `timing_history` runs roots or `MERLIN_CAPSULE_TIMING_HISTORY`),
then observed cycles, operand volume and name, after caller priority. Carried
certificates are not cost measurements. History orders work only: it never reuses,
skips or changes a result, and the profile refuses a certify budget.

The selected native component route spends one explicit wall deadline across
package build, all ordinary lowering commands, source checks, object/link,
execution, original output comparison and result publication. Failed attempt
evidence is retained after expiry; it cannot become a completed result.
Boundary checks do not preempt arbitrary in-process callbacks or confer any
semantic, physical or performance authority.

`native_component_inputs` owns the shared error identity and ordered tensor
binder reexported by `native_component_execution`; both import orders must work.
An explicitly selected original member supplies exact typed input storage and
the original full-output comparator without entering legacy golden dispatch.
Reopen that live owner before and after ordinary lowering/execution and keep
reference details in private evidence; caller-visible original failures contain
no expected values or private paths. Opaque pointer arity does not prove flat
tensor storage or a ranked memref descriptor bridge.

`owned_host_leaf_execution` grades reviewed host-only layers and model slices as
provided platform infrastructure. Reopen original source eligibility and require
zero accelerator-eligible operations before selecting fixed Merlin host lowering.
Candidates provide no host arithmetic. Keep complete typed inputs/outputs, actual
host compiler/object/link custody, whole-ELF accelerator prohibition and every
frozen numerical tier; missing native execution never passes. This grants no
candidate accelerator or host-code authorship credit.

`capsule_tier_result` owns the stable tier record serialization; the runner keeps
its historical class import/pickle identity. `capsule_lane_evidence` judges only
recorded execution, with the legacy counter map supplied by the runner.
`capsule_perf_ledger` publishes observations, taking current grader callbacks;
`native_model_values` decodes only frozen leaf bytes with the caller's error type.
All four are evaluator implementations and remain masked by common.access.

Explicit executed-program V2 retains the actual effective command buffer,
lowered LLVM, kernel object, complete console, build receipt and verified
original execution invocation per engine/ELF. V1 retains its original meaning.
Retention is bounded verification/setup work, never target execution cycles or
a numerical/certification verdict. Missing or changed V2 leaves cannot enable
final compiler-pass realization, even when the ordinary grade remains intact.

`native_pointer_source_binding` and `native_pointer_source_execution` are the
explicit standalone logical-pointer diagnostic. Preserve the candidate's actual
compiler_pointer_abi; never invent a whole-program ABI or global plan. Bind the
complete original typed source/declaration/reference order and captured signed
inputs before using the ordinary logical harness, selected build recipe and
full-value functional engine. V1 supports immutable signed-i8 entries and raw-i32
results with no source constants or nontrivial storage encodings. Bound compressed
array extents before allocation. Original live source/product/effect checks and
writer/private exclusion remain mandatory; an output match supplies no pass,
hardware, timing, placement or deeper-tier authority. Legacy model execution is
unchanged and cannot silently select this adapter.
`native_pointer_source_audit` reopens the same explicit pointer protocol for
normal finishing. Recompute typed storage, full source/build namespace, original
renderer/readback receipt, original LLVM-to-object-to-ELF producer chain and
same-ELF functional invocation before the shared
ISA and numerical audits. Recheck after those audits; changed custody revokes
passes. L0 describes this storage/build boundary only. Source arithmetic and
actual product/effect correspondence still require the independent live owner;
original required L3 remains pending under an explicit L2 ceiling.

`capsule_diagnostics` owns bounded source-free exception, simulator and output
diagnostics. It retains the runner's withheld grader identity; the runner keeps
its existing helper aliases, wrapper calls and numerical decisions.
