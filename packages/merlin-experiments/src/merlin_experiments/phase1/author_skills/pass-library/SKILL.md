# Pass library

Generated by `build_tools/scripts/gen_author_pass_library.py` from `docs/design/joint_optimization_catalog.json` (sha256 702b89f945126936) and the compiler source; do not edit.

1. Find the facets for what limits the case (table below; the same mapping the performance brief uses).
2. Open `reference/<facet>.md`; each entry names the call, its signature, when it applies, what your target supplies and a test line that calls it.
3. `OPTIMIZATION_SUGGESTIONS.json` in your workspace says which mechanisms your target's traits support; `python optimization_suggest.py --ir <source> --output <file>` checks workload prerequisites.
4. Call it through `scheduling-api`; compare cycles on the same cases before keeping it.
