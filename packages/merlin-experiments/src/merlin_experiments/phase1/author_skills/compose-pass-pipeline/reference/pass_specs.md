# Declared pass contracts (generated)

Generated by `python scripts/pass_specs.py --reference` from the library as shipped; a test fails
when it is stale. Rows are in source order (an inserted pass appears where it is declared, with
the `rewire` that adds its product to the consumer). `<expr>` is computed at run time. Your
workspace may hold a subset or an edited copy: rerun the script on your own tree for line numbers.

## Entry-point stage orders (`compile_trace.declare`)

- `frontend` via `merlin.compile_cli` (merlin.compile_cli): capture
- `codegen` via `merlin.llvmlower.codegen` (merlin.llvmlower.codegen): object -> link
- `llvm` via `merlin.llvmlower.lower_model` (merlin.llvmlower.lower): input -> source-recomputed -> host-graph-optimized -> host-row-scheduled -> host-padding-gather-forwarded -> host-destination-reused -> host-rounding-selected -> host-permutation-forwarded -> host-tensor-preparations-shared -> operation-profiled -> <*PREPROCESS_STAGES> -> upstream -> upstream-scheduled -> llvm-translated -> llvm-dialect -> llvm-normalized -> llvm-final
- `whole-model` via `merlin.perf.whole_model_build.build` (merlin.perf.whole_model_build): passes -> statement -> group_objects -> extract -> render_kernels -> program_build -> memory_map -> oracle_join
- `staged` via `merlin.xdsl_dialects.lowering.lower_module` (merlin.xdsl_dialects.lowering.pipeline): input -> contract -> schedule -> interface -> target -> runtime
