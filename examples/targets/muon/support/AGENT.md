# Muon support ownership

This standalone local repository owns Muon runtime, code generation and oracle
support. It is not a compiler candidate and has no configured publication remote.
Shared Merlin code must not regain copies of these target-specific implementations.

Preserve original provenance records; subsequent fixes need separate attribution.
Keep oracle code and support resources outside candidate grants. Facts, external
toolchains and hardware need explicit provisioning and qualification.
Do not run native compilers or simulators as part of import or migration tests.
