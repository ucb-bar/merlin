# Functional compiler experiment

Public authored prompts live in `task/`, selected explicitly by the shared target
descriptor's `task_root`. Keep grader implementations, private oracle inputs and
generated bundles out of examples. Never change archived tasks or run receipts.

The public curated harness in `contracts/harness_curated/` is selected by
`contracts_root`. Preserve vendor licenses and internal linker-script aliases.
The legacy harness path is a navigation link for retained experiment variants, not
a new source owner or proof that an old frozen run is safe to resume. The external
Chipyard bring-up links remain separate migration work; do not copy their referents.
