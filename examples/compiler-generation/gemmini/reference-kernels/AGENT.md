# Expert reference corpus

This directory owns the pinned public/reference input selection and its offline
preparation instructions. The generic corpus builder lives in the optional mining
package. Large unpacked originals and generated databases live under the configured
kernel-mining artifact root, not in Git or compiler source packages.

Preserve exact-byte identities and occurrence mappings. A stripped binary's inferred
static span is not a named source function or logical layer. Do not merge numerical
recipes, infer semantic equivalence from identical code bytes, or turn a source-name
match into a verified build relation. Keep unresolved analyses explicit.

This corpus is for explicit reference-assisted tooling studies. Precomputation does
not modify author profiles, frozen runs, or original grants. Export observations
without choosing compiler optimizations or exposing grading answers.
