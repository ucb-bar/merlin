# Functional compiler experiment

Public authored prompts live in `task/`, selected explicitly by the shared target
descriptor's `task_root`. Keep grader implementations, private oracle inputs and
generated bundles out of examples. Never change archived tasks or run receipts.

The copied vendor harness and high-level kernel helpers have been removed.
Fresh authoring starts with the issued inert scaffold, independently extracted
RTL facts and a minimal software spec. Runtime support is separately derived and
qualified; historical task documents do not establish current launch authority.
Never supply a prior compiler, curated kernel library or handwritten measurement
adapter to backend generation or backend optimization.
