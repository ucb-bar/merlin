# AGENT.md - examples/tutorials

These are public, executable explanations of current APIs. Keep each concept in
one notebook, with small authored inputs, deterministic default cells and optional
live controls. Call real implementation owners; do not duplicate compiler/checker
algorithms in the presentation or create a tutorial-only compiler framework.

verification and actual execution evidence. Illustrative data never establishes
hardware support or measured performance. Missing prerequisites stay explicit.

Keep source outputs clear and generated executions under the configured output
root. The fixed tutorial runner executes each authored notebook once. Do not hide
new regression matrices, private references or historical results in these files.
