# AF19_attn_scaled_bf16_pt

AF19_attn_scaled_bf16_pt ports npu_model's `smolvla_attention`: single-tile softmax((Q @ K) * S) @ V, where S is a full elementwise scale/mask tile rather than a scalar. Q @ K is NOT Q @ K^T -- unlike AF3_attn_full -- because the second operand arrives already laid out for the contraction. Execution reference: atlas-npu `baremetal/assembly/smolvla_attention.S`, which carries two `VTRPOSE.XLU` (one per MXU weight push); npu_model's assembly has none, so the program it ships computes the transposed contraction on real hardware. DTYPE -- option (b), the promoted form: on hardware Q/K/V are fp8_e4m3 tiles, the scale is bf16, and the softmax probabilities are requantized to fp8 before the second matmul, whereas this capsule is bf16 throughout. Neither the fp8 operands nor the probs requantization survives a model2MLIR capture -- the cast lowers away -- so putting them in the loader would produce a golden the interface module does not compute, which is exactly the silent divergence this corpus is built to avoid. What the capsule does preserve is the op graph, the untransposed contraction, and the elementwise score scale.
